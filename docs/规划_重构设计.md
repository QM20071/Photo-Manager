## 一、总目标

把现有 UI 从"顶部工具栏 + 底部 Tab + 右侧相册栏"改成
"顶部工具栏 + 左侧栏 + 网格 + 右侧信息栏"的布局，
并把"点相册移动"改成"拖拽移动"。

参考对象：Eagle（仅参考布局，不追求功能对齐）。

### 交互规则

| 动作 | 结果 |
|---|---|
| 点 `未整理` | 网格显示未整理图片 |
| 点 `收藏` | 网格显示收藏图片 |
| 点 `相册` 文字 | 网格显示"所有相册"封面页 |
| 点 `▸` 三角 | 网格不动，下方展开相册子列表 |
| 点子列表里的相册名 | 直接进相册看照片 |

- 三项都显示数量
- 相册项 = `[▸] [相册]` 两个独立可点区域
- 顺序保持：未整理 / 收藏 / 相册

## 六、拖拽整理（核心交互改动）

### 旧机制

选中图 → 点左侧栏相册 → 移动

### 新机制

选中图 → 拖拽 → 拖到目标 → 松手 → 移动

### 放置目标

| 目标 | 行为 |
|---|---|
| 左栏相册项 | 移进该相册 |
| 左栏"未整理" | 从相册移回未整理（organize_status → unsorted） |
| 左栏"收藏" | 加收藏（不移动文件） |
| 网格里其他相册（相册封面页时） | 移进那个相册 |

### 视觉反馈

- 拖动中：显示拖动数量（如"3 张"）
- 悬停在可接收目标上：该目标高亮 + 边框
- 松开：立即执行移动

### 无确认对话框

松手就移，不弹确认。

### 保留的备用入口

右键菜单保留"移动到相册 ▸"子菜单。

### 边界

- 拖到"收藏" = 加收藏，不移动文件
- 拖到"未整理"时，如果图片本来就在未整理 → 无操作
- 拖拽失败 → 复用现有 `move_files` 的错误报告

### 实现牵连

- 左栏相册项要支持 `dragEnterEvent` / `dropEvent`
- 网格要支持 `startDrag`
- 拖拽数据用 `QMimeData` 传 image_id 列表
